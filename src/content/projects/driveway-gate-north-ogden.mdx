This North Ogden project is a good example of how we approach a custom gate: start
with how it should look and how it has to perform, then engineer the steel to match.

Because the gate sits near the canyon, wind load mattered as much as looks. We
sized the frame, posts, and hinges accordingly, then finished everything with our
in-house [powder coating](/powder-coating/) so it resists rust and fading through
Utah winters.
