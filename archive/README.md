# Archive

These are early design explorations, sample references, and decision-making
demos from the Tefco website redesign. They are **not part of the live site**
and are kept here for reference only.

| File | What it was |
|---|---|
| `Sample1–4.png` | Inspiration screenshots the client shared early on |
| `tefco-design-1-editorial.html` … `-4-studio.html` | First four homepage concepts (rejected) |
| `tefco-sample1-mockup.html`, `tefco-sample4-mockup.html` | Faithful rebuilds of sample layouts 1 & 4 |
| `tefco-structalab-mockup.html` | First hand-built StructaLab-style mockup |
| `structalab.html` | The StructaLab Vite app converted to standalone HTML (design reference for the final direction) |
| `tefco-homepage-mockup.html` | Very first homepage mockup |
| `tefco-services-options.html` | Demo of 4 "Our Services" section treatments (chose Option A) |
| `tefco-about-options.html` | Demo of 4 about-section scroll effects (chose parallax) |
| `tefco-website-style-guide.md` | Original print-derived style guide (superseded by `/STYLE-GUIDE.md`) |

The live design system lives in the project root: `tefco.css`, `tefco.js`,
`tefco-elements.html`, `tefco-sections.html`, and `STYLE-GUIDE.md`.
